# Vibe-trainer для Android

Vibe-trainer написан на Kotlin и Jetpack Compose. Для входа используется аккаунт Fitness AI и код из письма.

Начните силовую тренировку в разделе «Тренировки», пока есть интернет. Во время занятия приложение сохраняет вес и повторы на телефоне и отправляет подходы после восстановления сети. После синхронизации тренировку можно завершить в приложении.

Из профиля можно открыть расписание, друзей, заметки, настройки и баланс. Аккаунтам с правами администратора доступно управление пользователями и платежами. Веб-админка также доступна на сайте.

Откройте каталог `android/native` в Android Studio или соберите APK из него с помощью JDK 17 и Android SDK 36.

```sh
./gradlew :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
```

APK появится в `app/build/outputs/apk/debug/app-debug.apk`. GitHub Actions публикует этот файл в артефакте `vibe-trainer-native-preview` после сборки и проверок. APK подписан отладочным ключом и устанавливается рядом с выпущенным Vibe-trainer. Перед удалением тестовой сборки дождитесь отправки записей.
