# Нативный дневник Vibe-trainer

Тестовая сборка открывает дневник силовых тренировок на Kotlin и Jetpack Compose. Она использует аккаунт Fitness AI и показывает сохранённую историю силовых тренировок.

1. При наличии сети войдите по коду из письма.
2. Начните силовую тренировку на сайте и нажмите «Обновить» в приложении.
3. Запишите вес и повторы напротив упражнения. Приложение сохраняет подход на телефоне сразу и отправляет его после восстановления сети.
4. После синхронизации завершите тренировку на сайте по ссылке из дневника.

Откройте каталог `android/native` в Android Studio или соберите APK из него с помощью JDK 17 и Android SDK 36.

```sh
./gradlew :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
```

APK появится в `app/build/outputs/apk/debug/app-debug.apk`. Сборка Preview устанавливается рядом с выпущенным Vibe-trainer. APK из GitHub Actions `Android native preview` подписан отладочным ключом сборочного окружения. Перед удалением Preview дождитесь отправки записей.
