# 3D-модель аватара мышц

Аватар на `/profile` по умолчанию рендерит **процедурную фигуру** из примитивов
(`components/avatar/PlaceholderBody.tsx`) — работает без ассета. Чтобы заменить
её на реалистичную анатомическую модель:

## 1. Получить модель

Источник: **Z-Anatomy** (мышечная система), лицензия **CC BY-SA 4.0** —
коммерческое использование разрешено при атрибуции + сохранении лицензии.
- Репозиторий: https://github.com/Z-Anatomy/Models-of-human-anatomy
- Или версия «Myology» на Sketchfab (только мышцы).

## 2. Подготовить glb (Blender)

1. Открыть .blend, оставить только мышечную систему (скрыть/удалить скелет,
   органы, нервы — нам нужны только мышцы).
2. Децимировать под веб-бюджет: цель **< ~8 МБ** glb (Decimate-модификатор,
   ratio ~0.2–0.4 — крутится на телефоне в 60fps).
3. Имена мешей оставить анатомическими (Pectoralis_major, Biceps_brachii,
   Biceps_femoris, Latissimus_dorsi, …) — резолвер
   `lib/avatar/muscle-mesh-map.ts` сводит их к 14 группам сам, различая омонимы
   (biceps brachii → руки, biceps femoris → бицепс бедра).
4. Экспорт: **glTF Binary (.glb)**, `+Y up`, применить трансформы.
5. Сохранить как `public/models/muscles.glb`.

## 3. Включить

В `lib/avatar/model-config.ts`:

```ts
export const MUSCLE_MODEL_URL: string | null = "/models/muscles.glb";
```

Всё. Раскраска (серый→красный по нагрузке), тап и вращение уже работают —
`MuscleModel` подхватит glb автоматически.

## 4. Проверить перед прод

Прогнать резолвер на реальных именах мешей модели (вытащить имена в Blender,
прогнать через `resolveMuscleKey`) — убедиться, что все 14 групп покрыты.
Непокрытые меши рендерятся нейтрально-серыми и не реагируют на тап.
