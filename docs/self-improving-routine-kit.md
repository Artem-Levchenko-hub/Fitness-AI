# Self-Improving Routine Kit — собери себе автономный цикл «исполнитель + рефактор»

Портативный шаблон. Два задания по расписанию работают с общими файлами в git-репозитории и **сами докручивают** твой проект, пока ты спишь. Умнеет не модель (она фиксирована) — умнеет **артефакт**: план и его реализация. Каждый запуск перечитывает прошлое состояние из файлов и делает следующий маленький шаг.

> Проверено на боевом проекте (Next.js SaaS на проде). Все грабли ниже — реальные, уже собранные за тебя.

---

## 1. Идея за 30 секунд

- **EXECUTOR** (каждые ~10 мин): читает план → берёт первую невыполненную задачу → делает ОДИН маленький проверенный слайс (код+тесты) → деплой → пишет результат в журнал.
- **REFACTOR** (каждые ~2 ч): читает план + журнал → критикует и переписывает ТОЛЬКО forward-roadmap (амбициознее/чище) → версионирует план + CHANGELOG. Код не пишет, не деплоит.
- **Чтобы не «поехало»:** фиксируешь **NORTH STAR** (рефактор его НЕ трогает) + версия плана + CHANGELOG (всё откатываемо через git).

Это всё. Магии нет — просто дисциплина в файлах + расписание.

---

## 2. Что нужно

- **Claude Code** (desktop-app или CLI) с поддержкой **scheduled tasks** (задания по расписанию).
- **git-репозиторий** проекта с рабочим `push` на trunk (токен в URL `origin` ИЛИ настроенный gh/ssh).
- Понимание, что задания идут в режиме **bypass permissions** (автономно, без подтверждений) — включается осознанно.
- Задания тикают **только пока app открыт И комп не спит**. Отключи сон: `powercfg /change standby-timeout-ac 0`.

---

## 3. Файл-драйвер плана (`CONTINUOUS-PLAN.md`)

Создай в репо `docs/plan/CONTINUOUS-PLAN.md` со СТРОГОЙ структурой (рефактор правит ТОЛЬКО §5★):

```markdown
# <ПРОЕКТ> — НЕПРЕРЫВНЫЙ САМОУЛУЧШАЮЩИЙСЯ ПЛАН
> ВЕРСИЯ ПЛАНА: v1.0 — <дата> (genesis)

## ★ NORTH STAR (НЕПРИКОСНОВЕННА — рефактор НЕ трогает)
<1 абзац: чего хочешь в идеале — словами заказчика>
4 столпа (каждая задача меряется по ним):
1. <столп 1>   2. <столп 2>   3. <столп 3>   4. <столп 4 — «сохранность: ничего из существующего не теряем»>

## §0. НЕРУШИМЫЕ ПРАВИЛА (прод-безопасность)
- Репо: <путь>. Прод: <url>. Trunk: <master/main>.
- GATE перед деплоем: <typecheck; lint; test; build>. Красное → СТОП, не деплоить.
- PUSH: git push origin HEAD:<trunk> (НЕ имя устаревшей ветки → non-ff).
- ДЕПЛОЙ: <команда>. Сначала проверь, что прод не правили вручную (git status --porcelain).
- Миграция БД? Сначала БЭКАП (pg_dump), потом migrate.
- НИКОГДА: не трогать чужие сервисы/процессы; не sudo без явной директивы.

## §0c. HARD-STOP HEARTBEAT (renewing dead-man)
HARD-STOP = <now+72ч>
- EXECUTOR: если now >= HARD-STOP → выключить себя, СТОП.
- REFACTOR: каждый тик катит HARD-STOP = now+72ч. Заброшено >72ч → обе рутины затухают сами.

## §5★. ВИЗИОНЕРСКИЙ ROADMAP (ЕДИНСТВЕННАЯ секция, которую правит REFACTOR)
- [ ] T1 <первая маленькая задача>
- [ ] T2 ...

## §6. ПРОГРЕСС (IN-FLIGHT трекер)
## §7. ЛОГ (append-only — НИКОГДА не переписывать прошлое; новое сверху)
## CHANGELOG ПЛАНА (рефактор дописывает сверху)
- v1.0 — <дата> (genesis)
```

## 4. Задание EXECUTOR (вставь как prompt scheduled-task, cron `3,13,23,33,43,53 * * * *`)

> Замени `<...>` под свой проект. Это самодостаточный prompt — будущая сессия НЕ помнит ничего, кроме файлов.

```
Ты — EXECUTOR непрерывного цикла <ПРОЕКТ>. ОДИН поток: одна задача за раз до зелёного, потом стоп. Свежая сессия без памяти; единственная память — <путь>/docs/plan/CONTINUOUS-PLAN.md. Доступ санкционирован (bypass) — не переспрашивай.
ОБЯЗАТЕЛЬНО каждый ран: sequential-thinking перед кодом; смотреть актуальные доки библиотек (context7) — не кодить по памяти; TDD (баг → failing-тест → фикс).
0. СТОП-ГЕЙТ: прочитай HARD-STOP из §0c. now >= HARD-STOP → выключи себя (update_scheduled_task enabled=false), СТОП.
1. LOCK (только против второго executor'а): файл ~/.claude/<проект>-routine.lock. Есть и моложе 25 мин → СТОП молча. Иначе запиши метку. Сними в конце ВСЕГДА. (Refactor lock НЕ использует — он в своём worktree.)
2. Прочитай CONTINUOUS-PLAN.md: NORTH STAR первым, §0/§0c, §5★, §6, хвост §7.
3. git fetch; git pull --ff-only origin <trunk>. Diverged → blocker в §7, СТОП.
4. Возьми первую [ ] из §5★ (или возобнови IN-FLIGHT). Один слайс ~1-3 файла.
5. sequential-thinking: распиши слайс + точный рантайм-тест.
6. Реализуй минимальным дифом. Для бага: репро → фикс → докажи что репро исчез. Добавь тест на изменение.
7. ДОСТАВКА: (a) GATE <typecheck;lint;test;build> — красное 2 раза → blocker §7, СТОП. (b) push origin HEAD:<trunk>; non-ff → pull --rebase + repush ×3. (c) деплой <команда>, build-gated. (d) рантайм-проверка как реальный юзер (браузер) — утверди поведение, НЕ «страница грузится»; ПОСЛЕ — ЗАКРОЙ браузер (browser_close). (e) красно → ищи root cause, чини до зелёного, не помечай done.
8. ЖУРНАЛ: [x] только при 3 зелёных (gate + тест на изменение + рантайм-доказательство). Блок в §7 (сверху, append-only). Docs-коммит. Сними lock.
9. RESOURCE-GUARD (бережём RAM): снеси ТОЛЬКО осиротевшие (dead-parent) процессы — orphan MCP-node + headless-chromium + бесхозные cmd/conhost. Живые сессии/чужие сервисы НЕ трогай.
Ровно ОДНА задача за запуск.
```

## 5. Задание REFACTOR (cron `49 */2 * * *`) — РАЗВЯЗАН через свой git-worktree

> Ключевая идея: рефактор работает в **отдельном worktree**, поэтому НИКОГДА не блокируется работой executor'а/твоей и проходит в любом случае.

```
ultracode
Ты — РЕФАКТОР-КАРЕТЕЙКЕР цикла <ПРОЕКТ>. Каждые 2ч критикуешь и переписываешь ТОЛЬКО §5★ roadmap под NORTH STAR. Код НЕ пишешь, НЕ деплоишь. Свежая сессия; память — CONTINUOUS-PLAN.md. Доступ санкционирован.
1. ИЗОЛИРОВАННЫЙ WORKTREE (проходишь В ЛЮБОМ СЛУЧАЕ, НЕ блокируешься, НЕ трогаешь рабочую папку executor'а; НЕТ lock, НЕТ ожидания):
   - worktree-путь <WT> (вне основного репо, желательно БЕЗ нелатинских символов в пути).
   - git -C <main> fetch origin; если worktree нет: git -C <main> worktree add --detach <WT> origin/<trunk>; если есть: git -C <WT> fetch origin; git -C <WT> reset --hard origin/<trunk> (worktree одноразовый).
   - Все операции — в <WT>. Основную папку НЕ трогай.
2. Прочитай из <WT>/docs/plan/CONTINUOUS-PLAN.md: NORTH STAR (read-only), §0c, §5★, хвост §7 (что executor реально сделал), CHANGELOG. git log -20.
3. КРИТИКА (глубоко; можно multi-agent через Workflow). RAM-CAP: не более 3 суб-агентов одновременно, волнами; суб-агенты one-shot. Линзы: каждый столп NORTH STAR; амбиция/local-maxima; мёртвое/устаревшее (убрать). Синтез → одно предложение по §5★. План здоров → no-op (YAGNI).
4. ПЕРЕПИШИ ТОЛЬКО §5★ (сохрани [x]/[~]). НЕЛЬЗЯ трогать NORTH STAR/§0/§7-ЛОГ.
5. HARD-STOP: обнови §0c = now+72ч.
6. ВЕРСИЯ+CHANGELOG: bump версии, запись сверху (что и ЗАЧЕМ).
7. ДОСТАВКА (docs-only, из <WT>): git add docs/plan/CONTINUOUS-PLAN.md → commit --no-verify (worktree без node_modules → pre-commit hook упадёт; markdown typecheck не нужен; код ты не коммитишь) → push origin HEAD:<trunk>; non-ff → fetch + reset --hard origin/<trunk> + ЗАНОВО примени синтез + repush ×3.
8. RESOURCE-GUARD: снеси ТОЛЬКО осиротевшие (dead-parent) процессы.
Один прогон = одна осмысленная докрутка плана. Не дублируй executor'а, не трогай ядро.
```

## 6. Грабли (уже собраны — не наступай)

1. **Один shared lock = рефактор голодает.** Если обе рутины делят lock, а работа идёт всегда, рефактор молча скипает каждый тик. **Решение:** lock только executor↔executor; рефактор — в своём **git-worktree**, lock не трогает. Стыкуются только через `origin/<trunk>` с non-ff retry.
2. **worktree без `node_modules`.** Pre-commit hook (typecheck/lint) упадёт в worktree. **Решение:** docs-only коммит рефактора идёт с `git commit --no-verify` (markdown не нужен typecheck; рефактор код не коммитит).
3. **RAM-взрыв от MCP-флота.** Каждая сессия Claude грузит ВЕСЬ набор MCP-серверов (~9 node-процессов). Multi-agent на 8 суб-агентов = 70+ node / ~9 ГБ. **Решение:** RAM-CAP ≤3 суб-агента волнами; **RESOURCE-GUARD** в конце ранов сносит осиротевшие процессы (только dead-parent!); отключи неиспользуемые MCP-серверы в конфиге.
4. **Стрэй intent/lock-файл блокирует.** Старый координационный файл, забытый на диске, тихо тормозит рутину. **Решение:** чистые dead-man таймауты + удаляй свои файлы в конце ВСЕГДА.
5. **Устаревшее имя ветки в push.** `git push origin <стараяВетка>:<trunk>` → non-ff. **Решение:** всегда `git push origin HEAD:<trunk>`.
6. **Нелатинский путь репо.** Опечатки в кириллических/юникод-путях плодят левые папки. **Решение:** worktree клади по латинскому пути; проверяй путь после записи.
7. **HARD-STOP dead-man.** Без него рутины крутятся вечно. Рефактор катит горизонт +72ч каждый тик; забросил проект >72ч → само затухнет.

## 7. Быстрый старт (чеклист)

1. [ ] Создай `docs/plan/CONTINUOUS-PLAN.md` (§3), впиши свой NORTH STAR + первые 3-5 задач в §5★.
2. [ ] Закоммить план в trunk (рутины читают его оттуда).
3. [ ] Создай scheduled-task EXECUTOR (§4), cron `3,13,23,33,43,53 * * * *`.
4. [ ] Создай scheduled-task REFACTOR (§5), cron `49 */2 * * *`.
5. [ ] Инициализируй `HARD-STOP = now+72ч` в §0c.
6. [ ] Отключи сон компа; оставь app открытым.
7. [ ] Дёрни «Run now» на каждой задаче раз — пред-одобрить инструменты.
8. [ ] Утром читай §7 ЛОГ + CHANGELOG — видно, что нарасло за ночь.

Готово. Цикл сам докручивает проект к твоей путеводной звезде, маленькими проверенными шагами, и сам себя останавливает, если ты его забросишь.
