# Как помочь Fitness AI

Спасибо за интерес к проекту. Здесь ценятся небольшие, понятные изменения,
которые можно проверить независимо.

## Перед началом

1. Найдите похожий запрос в [Issues](https://github.com/Artem-Levchenko-hub/Fitness-AI/issues).
2. Для заметного изменения сначала создайте feature request и опишите
   пользовательскую пользу.
3. Для исправления ошибки укажите минимальные шаги воспроизведения.
4. Не публикуйте секреты, персональные или платёжные данные.

## Рабочий процесс

```bash
git switch -c feat/short-name
pnpm install
pnpm typecheck
pnpm lint
pnpm test
```

Подробная настройка: [docs/development.md](docs/development.md).

Pull request должен:

- решать одну связанную задачу;
- описывать изменение поведения;
- содержать тесты для новой логики;
- не включать случайное форматирование других файлов;
- перечислять миграции, переменные окружения и риски;
- прикладывать скриншоты для заметного UI-изменения.

## Правила для БД и платежей

- Не изменяйте историю применённых миграций.
- Денежные значения храните в целых копейках.
- Любая операция баланса должна быть идемпотентной и транзакционной.
- Webhook не считается доверенным источником платёжных полей.
- Live billing, production и Google Play не включаются без отдельного решения
  владельца.

Участие означает согласие с [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
